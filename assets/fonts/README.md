# Font Files Required

To complete the accessibility implementation, please download and add the following font files:

## Noto Sans Devanagari (for Hindi support)
- NotoSansDevanagari-Regular.ttf
- NotoSansDevanagari-Medium.ttf
- NotoSansDevanagari-SemiBold.ttf
- NotoSansDevanagari-Bold.ttf

Download from: https://fonts.google.com/noto/specimen/Noto+Sans+Devanagari

## Noto Sans Gujarati (for Gujarati support)
- NotoSansGujarati-Regular.ttf
- NotoSansGujarati-Medium.ttf
- NotoSansGujarati-SemiBold.ttf
- NotoSansGujarati-Bold.ttf

Download from: https://fonts.google.com/noto/specimen/Noto+Sans+Gujarati

## Installation Instructions
1. Download the font files from the Google Fonts links above
2. Place them in the `assets/fonts/` directory
3. Ensure the file names match exactly as specified in `pubspec.yaml`
4. Run `flutter clean` and `flutter pub get` after adding the fonts

## Note
These fonts are essential for proper rendering of Hindi (Devanagari) and Gujarati scripts in the accessibility features.
